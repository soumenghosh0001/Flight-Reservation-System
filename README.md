# Flight Reservation System

A responsive flight reservation web application built using HTML, CSS, and JavaScript. The project simulates an airline booking interface with interactive UI components and dynamic user interactions.

## Features
- Flight search interface
- Ticket booking form
- Responsive user interface
- Form validation using JavaScript
- Interactive flight selection system
- Clean and modern design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Concepts Used
- DOM Manipulation
- Responsive Web Design
- Event Handling
- Form Validation
- Frontend Web Development
